A one-line joke writer for make.fun's "One Line, Big Laugh" bounty. Running `main.py` writes a single 150-character joke to `/output/entry.txt`:

> My password manager locked me out for suspicious activity. The suspect: me, at 2:47 a.m., googling my own birthday to answer my own security question.

The program is deterministic: it writes the same line on every run, with no network access and no randomness.

## Run it

```sh
python3 main.py
```
